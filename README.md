# Smart Waste Management and Eco-Reward System

## Project Overview

The Smart Waste Management and Eco-Reward System is a responsive landing page designed to promote responsible waste disposal, recycling awareness, and environmental sustainability. The system encourages users to participate in waste management activities and earn eco-reward points for their contributions.

## Objective

The main objective of this project is to create awareness about proper waste management practices and motivate users to contribute towards a cleaner and greener community through an eco-reward mechanism.

## Features

* Waste Collection Request Tracking
* Eco Reward Points System
* Recycling Support and Awareness
* Community Cleanliness Promotion
* AI Waste Management Tips
* Responsive User Interface
